Translator credits

The game-chat glossary, shorthand expansion and numeric validation are browser adaptations of zhuffman68/Lupin, from the user-supplied lupin-main.zip. Original source modules: price_lens/chat_text.py and price_lens/outgoing_text.py.

Lupin’s Python/Qt capture, PaddleOCR and CTranslate2 workers are replaced here with browser screen sharing, Tesseract.js and browser-local translation. This is an adaptation, with a selected reading area, rather than Lupin’s desktop overlay and whole-window bubble detection.

Browser-native translation is used when available. The fallback uses NLLB-200 distilled 600M (Meta; ONNX conversion by Xenova), licensed under CC BY-NC 4.0. It is intended for noncommercial use. Inference runs on the device; model files download from Hugging Face.

Transformers.js (Apache-2.0), pinned v3.8.1, loads from jsDelivr. Tesseract.js (Apache-2.0) and Tesseract language data (Apache-2.0) provide optional Korean OCR. Existing runtime notices are in assets/ocr. Korean/English recognition data downloads from Project Naptha.

Text, screenshots and recent translations remain in memory in this tab. Clearing or closing it removes the history. Downloaded models may remain in the browser cache. Translation and OCR can be inaccurate; originals stay visible. Nothing automatically types or sends messages to the game.
